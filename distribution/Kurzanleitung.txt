SquadTimer – Installation unter Windows
======================================

Vor dem Start
-------------
Docker Desktop für Windows muss installiert sein und laufen, sonst kann
SquadTimer nicht starten. Du brauchst die x86_64-Version für einen x64-PC.
Offizieller Download und Installationsanleitung von Docker:
https://docs.docker.com/desktop/setup/install/windows-install/
Lass Docker Desktop im Standardmodus für Linux-Container laufen.

Die Docker-Images sind im öffentlichen Windows-ZIP enthalten. Ein GitHub-Konto
oder eine Registry-Anmeldung ist für dieses Paket nicht nötig. Squad muss beim
Start der App nicht geöffnet sein. Der lokale Port 8080 muss frei sein.

Schritt für Schritt
-------------------
1. Öffne Docker Desktop und warte, bis es bereit ist.
2. Lade unter https://github.com/buzzibaer/SquadTimer/releases/latest
   das Windows-ZIP aus dem Bereich „Assets“ herunter, falls es dir noch fehlt.
3. Rechtsklick auf das ZIP → „Alle extrahieren…“. Öffne den entpackten Ordner.
4. Doppelklicke auf „SquadTimer starten.cmd“. Lass das Startfenster offen,
   bis sich der Browser öffnet. Der erste Start kann etwas länger dauern.
5. Falls sich kein Browser öffnet, rufe http://127.0.0.1:8080 auf. Zeigt das
   Startfenster einen Fehler, behebe diesen zuerst.

Ist der Squad-Logordner vorhanden, kann die App Karte und Layer automatisch
erkennen. Sonst kannst du sie manuell wählen. Legt Squad den Ordner erst
später an, starte SquadTimer erneut.

Zum Beenden: „SquadTimer stoppen.cmd“ doppelklicken. Deine Runde bleibt im
selben Browserprofil gespeichert.

Ausführliche Anleitung und Fehlerhilfe:
https://github.com/buzzibaer/SquadTimer/blob/main/INSTALLATION.md
